# Puzzle IQ

Jeu de puzzle en JavaScript (HTML/CSS/SVG).

## Lancer le jeu

1. Ouvrir le dossier du projet dans VS Code.
2. Ouvrir `index.html` dans un navigateur.

## Comment jouer

1. Choisir la largeur et la hauteur.
2. Cliquer sur **Commencer**.
3. Clic gauche sur une piece: la prendre.
4. Clic gauche une seconde fois: la poser.
5. Clic droit pendant qu'une piece est en l'air: rotation de 90 degres.
6. Bouton **Tout remettre**: remettre les pieces disponibles.
7. Bouton **Generer nouveau**: creer une nouvelle grille.

## Structure du projet

- `index.html`: structure de la page
- `style.css`: styles et mise en page
- `script.js`: logique du jeu

## Notes techniques

- Encodage recommande: **UTF-8** pour tous les fichiers texte.
- Le dossier `venv/` est ignore par Git et ne doit pas etre versionne.
